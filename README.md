# 💰 Personal Finance Dashboard

A sleek, responsive, and interactive Personal Finance Dashboard built with modern frontend technologies. This application helps users track their income, monitor expenses, visualize spending categories, and stay on top of their financial goals with clean, dynamic charts.

## ✨ Features

* **Financial Overview Summary:** Real-time tracking of total balance, monthly income, total expenses, and savings metrics at a glance.
* **Interactive Data Visualizations:** Dynamic charts and graphs breaking down spending habits by category (e.g., Food, Utilities, Entertainment, Savings).
* **Transaction Management:** Add, view, and filter recent income and expense transactions.
* **Responsive Design:** Fully optimized layout for desktop, tablet, and mobile screen sizes.
* **Local Storage Integration:** Persists user data locally so entered transactions and updates remain saved across sessions.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Flexbox/Grid), Modern JavaScript (ES6+)
* **Styling / Icons:** CSS Variables, FontAwesome / Lucide Icons
* **Charts & Graphs:** Chart.js / Custom Canvas Rendering
* **Version Control:** Git & GitHub
